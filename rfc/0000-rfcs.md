# RFC definition

This document specifies how RFC documents should be structured.

## Decisions

- RFCs must be lean documents.
- RFC files live inside `rfc/` folder.
- File names follow the format `0000-short-slug.md`.
- Mandatory title `# Short RFC Title`.
- Mandatory brief description after title.
- Mandatory `## Decisions` section.
- Decisions contain concise bullet list of decisions taken.
- Mandatory `## Checks` section.
- Checks contain a list of agent-executable instructions.
- Checks list uses `- [ ] unfinished check`.
- Checks list uses `- [X] implemented check`.
- All checks passing means status is `done`.
- Mandatory frontmatter:
  ```yaml
  ---
  status: wip | done
  ---
  ```

## Checks

- [x] `rfc/` folder is created.
- [x] file names inside `rfc/` follow format.
- [x] file `rfc/0000-rfcs.md` exists.
- [x] file `rfc/0000-rfcs.md` contains mandatory sections.
- [x] test for all files inside `rfc/` have mandatory sections (use glob)
